# App Store Screenshots

This directory is for storing screenshots of the Slotted app for App Store submission.

## Required Screenshot Sizes

For iPhone:
- 6.5" Super Retina Display: 1242 x 2688 pixels (iPhone 11 Pro Max, iPhone XS Max)
- 5.8" Super Retina Display: 1125 x 2436 pixels (iPhone 11 Pro, iPhone X, iPhone XS)
- 6.1" Liquid Retina Display: 828 x 1792 pixels (iPhone 11, iPhone XR)
- 5.5" Retina Display: 1242 x 2208 pixels (iPhone 6 Plus, iPhone 6s Plus, iPhone 7 Plus, iPhone 8 Plus)
- 4.7" Retina Display: 750 x 1334 pixels (iPhone 6, iPhone 6s, iPhone 7, iPhone 8, iPhone SE 2nd gen)

## Screenshot Guidelines

1. Take screenshots that showcase the main features of the app:
   - Home screen with events
   - Event details page
   - Profile page
   - Payment process
   - Apple Pay integration

2. Make sure the screenshots are visually appealing and highlight the app's UI.

3. Consider adding text overlays to explain key features.

4. Ensure there is no sensitive or test data visible in the screenshots.

5. Name the files consistently, for example:
   - 01_home_6.5.png
   - 01_home_5.8.png
   - 02_event_details_6.5.png
   - etc.

## How to Take Screenshots

1. Run the app on the appropriate device or simulator.
2. Navigate to the screen you want to capture.
3. Press Power + Volume Up buttons simultaneously (physical device) or Command + S (simulator).
4. Edit the screenshots if needed to add text overlays or other enhancements.
5. Place the final screenshots in this directory.

Remember that high-quality screenshots can significantly impact the app's conversion rate in the App Store.
