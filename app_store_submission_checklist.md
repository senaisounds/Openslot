# App Store Pre-Submission Checklist

## Required Items
- [ ] App has been tested on multiple physical iOS devices
- [ ] All critical bugs have been fixed
- [ ] App icon is properly set up (verified)
- [ ] Privacy policy URL is valid and accessible
- [ ] Support URL is valid and accessible
- [ ] All placeholder text has been removed from the app
- [ ] App description and keywords are prepared (verified)
- [ ] Screenshots are ready for all required device sizes
- [ ] Version number is correctly set (verified: 1.0.95+128)

## Technical Requirements
- [ ] App works in airplane mode or with poor connectivity
- [ ] All external links open properly
- [ ] No crashes or freezes occur during normal usage
- [ ] All permissions requests have appropriate explanations (verified)
- [ ] All third-party login methods work correctly
- [ ] Payment processing works reliably
- [ ] Push notifications are properly configured
- [ ] App performance is acceptable on older devices

## App Content
- [ ] All images and assets are properly licensed
- [ ] No placeholder or debugging content is visible
- [ ] Error messages are user-friendly
- [ ] Loading states and progress indicators work correctly

## App Store Requirements
- [ ] Demo account is ready for App Review team
- [ ] App review notes are prepared
- [ ] Age rating information is accurate
- [ ] App respects all App Store Review Guidelines

## Final Verification
- [ ] Create a production build and test it on actual devices
- [ ] Verify all APIs work with production endpoints
- [ ] Ensure Firebase/backend configurations are set for production
- [ ] Test all user flows from onboarding to core functionality
